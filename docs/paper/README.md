# 논문 작성 문서

이 폴더는 Notion 논문 페이지와 동기화하는 근거 기반 작성본을 보관한다.

- `paper-outline-ko.md`: 논문 전체를 한국어 개조식으로 정리한 작성 설계서
- `manuscript-draft-ko.md`: 개조식 설계서를 줄글로 전환한 결과 확정 전 초안
- `paper-outline-stage3-ko.md`: 공식 실행 결과와 Pareto 결론을 반영한 Stage 3 개조식 구성안
- `manuscript-draft-stage3-ko.md`: 같은 근거를 문장형으로 전개한 Stage 3 줄글 초안
- `stage3-evidence-map.md`: 최종 실험 결과를 논문 주장과 연결하는 근거표

확정 수치는 저장소의 설정·JSON·보고서에서만 가져온다. 저장소에 근거가 없는
정보는 문서 안에 `[GitHub 근거 없음]`으로 표시한다. 파일명에 Stage 3가 없는
구성안과 줄글 초안은 Stage 2 실행 전 스냅샷으로 보존한다. 실제 논문 작성과
Notion 동기화에는 `paper-outline-stage3-ko.md`와
`manuscript-draft-stage3-ko.md`를 사용한다. 수치가 충돌하면 GitHub의 자동 생성
결과와 설정 파일을 우선한다.
