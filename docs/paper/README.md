# 논문 작성 문서

이 폴더는 Notion 논문 페이지와 동기화하는 근거 기반 작성본을 보관한다.

- `paper-outline-ko.md`: 논문 전체를 한국어 개조식으로 정리한 작성 설계서
- `manuscript-draft-ko.md`: 개조식 설계서를 줄글로 전환한 결과 확정 전 초안
- `stage3-evidence-map.md`: 최종 실험 결과를 논문 주장과 연결하는 근거표

확정 수치는 저장소의 설정·JSON·보고서에서만 가져온다. 저장소에 근거가 없는
정보는 문서 안에 `[GitHub 근거 없음]`으로 표시한다. 현재 구성안과 줄글 초안은
Stage 2 실행 전 스냅샷이므로 남아 있는 `[Stage-2 후 삽입]`과 `[Stage-3 후 삽입]`
표시는 다음 Stage 3 원고 갱신에서 교체한다. 최신 확정 입력은
`stage3-evidence-map.md`와 `../reports/stage3-final-analysis.md`이며, Notion과
충돌하면 GitHub의 자동 생성 결과와 설정 파일을 우선한다.
