# FP16 경량화 정리

## FP16이란?

FP16은 모델에서 사용하는 부동소수점 숫자를 32비트(FP32) 대신
16비트로 표현하는 방식이다.

```text
FP32: 숫자 하나당 4 bytes
FP16: 숫자 하나당 2 bytes
```

모델 구조와 파라미터 개수는 그대로 유지하면서 각 숫자의 표현 크기를
줄인다. 따라서 가중치 저장 공간과 GPU 메모리 사용량을 줄일 수 있고,
Tensor Core를 지원하는 NVIDIA GPU에서는 추론 속도도 개선될 수 있다.

FP16은 FP32보다 표현 범위와 정밀도가 작으므로 confidence, bounding box,
segmentation mask 및 최종 정확도에 변화가 없는지 반드시 검증해야 한다.

## PyTorch FP16

PyTorch FP16은 기존 `.pth` checkpoint를 그대로 사용하면서 실행 시
연산 정밀도를 FP16으로 변경하는 방식이다.

```python
with torch.autocast(device_type="cuda", dtype=torch.float16):
    output = model(image)
```

모델 파일은 동일하다.

```text
artifacts/training/front-rfdetr-seg-large-v1/checkpoint_best_total.pth
├── 일반 실행              → PyTorch FP32
└── CUDA autocast 적용     → PyTorch FP16
```

따라서 별도의 FP16 checkpoint를 반드시 만들 필요는 없다. 주요 산출물은
다음과 같다.

- FP16 실행 및 벤치마크 코드
- 추론 시간과 FPS
- GPU 메모리 사용량
- FP32 대비 정확도 변화

## TensorRT FP16

TensorRT FP16은 PyTorch checkpoint를 ONNX로 변환한 후, NVIDIA GPU에
맞게 최적화된 별도의 TensorRT engine을 생성하는 방식이다.

```text
PyTorch checkpoint
→ ONNX
→ TensorRT FP16 engine
```

예상 산출물:

```text
artifacts/experiments/
├── B01/<camera>/model.onnx
└── B02/<camera>/model.engine
```

TensorRT는 FP16 적용 외에도 연산 결합, 불필요한 연산 제거, 메모리
최적화 및 GPU별 커널 선택을 수행한다. 따라서 PyTorch FP16보다 빠를 수
있지만, 속도 향상이 FP16 때문인지 TensorRT 최적화 때문인지 구분해서
분석해야 한다.

TensorRT engine은 GPU, CUDA 및 TensorRT 버전에 영향을 받을 수 있다.
재현성을 위해 원본 ONNX, 변환 명령, GPU 정보와 TensorRT 버전을 함께
기록해야 한다.

## 이번 프로젝트의 FP16 실험군

| ID | Framework | Precision | 모델 파일 |
|---|---|---|---|
| B0 | PyTorch | FP32 | 기존 `.pth` |
| F0 | PyTorch | Mixed FP16 | 기존 `.pth` |
| F1 | TensorRT | FP16 | 별도 `.engine` |

비교 항목:

- 모델 또는 engine 파일 크기
- 평균·중앙값·p95 추론 시간
- FPS
- GPU 메모리 사용량
- detection 정확도
- segmentation mask 정확도

## 구현 순서

1. PyTorch FP32 baseline 측정
2. 같은 checkpoint를 CUDA autocast FP16으로 측정
3. checkpoint를 ONNX로 변환
4. NVIDIA 장비에서 TensorRT FP16 engine 생성
5. 동일한 입력과 조건으로 세 실험군 비교

NVIDIA GPU 장비에서 등록된 FP16 실험을 생성하려면 다음 명령을 사용한다.

```bash
.venv/bin/python scripts/experiments/build_candidate.py B02 \
  --camera front --target engine
```

핵심 차이는 다음과 같다.

> PyTorch FP16은 기존 `.pth`를 실행할 때 FP16 연산을 적용하는 것이고,
> TensorRT FP16은 별도의 NVIDIA 최적화 `.engine` 파일을 생성하는
> 방식이다.
