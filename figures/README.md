보고서와 논문에 삽입하는 PNG/PDF를 둔다. 원시 수치를 손으로 수정하지 않고

`stage3_mask_latency.png`과 `stage3_mask_engine_size.png`은 정확도 gate와 Pareto
관계, `stage3_latency_cv.png`은 공식 지연시간 반복 측정의 안정성을 보여준다.
